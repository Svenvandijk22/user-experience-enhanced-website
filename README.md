## Beschrijving
tijdens deze sprint ben ik bezig geweest met het verbeteren van de User experience door middel van client side java script ook heb ik ene chat bot verbeterd door hem beter schaalbaar te maken voor mobiel en heb ik me gefocus deze sprint op de performnce van mijn website.


## User experience

op mijn milledoni website kan je producten toevoegen aan een verlanglijsje dit heb ik gedaan met een post in de vorige sprint nu heb ik me gefocused op de ux en dat de gebruiker feedback krijgt dat er een product aan het verlanglijsje wordt toegevoegd dit heb ik gedaan door middel van een loading state en succes state ik heb in deze issue het hele ontwerp de flow hoe mijn client side java script er uitkomt te zien in staan: https://github.com/Svenvandijk22/user-experience-enhanced-website/issues/10


## Frontend performance

ik heb ook een performnce audit gedaan op mijn website die staat in deze issue gedocumenteerd: https://github.com/Svenvandijk22/user-experience-enhanced-website/issues/11


## ontwerp lijsjes

Ik ben deze sprint naast het verbetren van de ux en performnce ook bezig geweest met het nieuwe ontwerp van mijn licked products pagina (de pagina waarin alle gelikte producten staan) opmilledoni kan je meerdere lijsten maken en andere lijsten van andere mensen bekijken dit was een van de vragen van de opdrachtgever dat we hier naar zouden kijken ik heb mijn ontwerp staan in een issue waarin ik heb ontwerp beargumenteerd: https://github.com/Svenvandijk22/user-experience-enhanced-website/issues/13


## Gebruik
User story: Als gebruiker wil ik cadeaus kunnen toevoegen aan mijn verlanglijstje, zodat ik mijn cadeaus kan bewaren en later makkelijk terugvinden.
